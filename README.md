# StayMaestro

Standalone site for StayMaestro by Stonemont Capital: fractional property management for short term rentals.

- Static, one page: `index.html`, images in `images/`. No build step.
- Meant for GitHub Pages from `main` (root): https://gidspen.github.io/staymaestro/ until a custom domain is set.
- The same page also lives at stonemontcap.com/staymaestro (repo `gidspen/stonemontcap`, `staymaestro/index.html`). Keep the two in sync: only the image paths and `og:url` differ.
- Custom domain: add a `CNAME` file with the domain only after its DNS points at GitHub Pages, or the github.io address will redirect to a dead domain.
